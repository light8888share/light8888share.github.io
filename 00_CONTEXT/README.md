# LinkTree モジュール・コンテキスト

このフォルダは、トレンド情報やおすすめAIツールを発信する「AI Navigator / ライト」のリンクツリー型Webサイトを管理する独立したフロントエンド環境です。

## モジュールの目的
- TrendBot で生成された最新トレンド記事や、SNS投稿用の情報を整理してユーザーに届ける（アウトプットの窓口）。
- アフィリエイト収益の最大化を目指した、デザイン、UI/UXの改善。
- GitHub Pages 等へのデプロイ管理。

## ページ構成
- `index.html`: トップページ。プロフィール、主要リンク、おすすめツール（Hot Picks）の一覧。
- `articles.html`: 週次まとめ記事の一覧ページ。
- `trends.html`: 日次トレンド記事のバックナンバーを日付別に表示。
- `articles/*.html`: 各週のまとめ記事の詳細。
- `style.css`: 全ページ共通のモダンなダークモードデザイン。

## インターフェース（データ受取りルール）
- **トレンドデータ**: `trends.html` の `<!-- TREND_HISTORY_START -->` マーカー内に新しいトレンドブロックを挿入。
- **まとめ記事**: `articles.html` の `<!-- ARTICLES_LIST_START -->` マーカー内に新しい記事リンクを挿入。
- **デプロイ**: `deploy.sh` を実行することで、GitHub Pages へプッシュされる。

## UI/UX ルール
- **配色**: サイトのトーンを崩さないダークモード（ブルー、シアン、スレート系の配色）。
- **モバイル優先**: スマホで見た際の操作（コピー＆ペーストのしやすさ、ボタンの押しやすさ）を最優先する。
- **アフィリエイト**: 自然かつクリックしたくなる導線設計。

---
※このモジュールは、AIエージェントに「デザインをより高級感のあるものにして」「新しいカテゴリを追加して」と指示する際の表示ルール集です。
